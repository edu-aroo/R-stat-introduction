Common errors and pitfallsErreurs et pièges fréquents

R messages of statistical functions, and the classic statistical mistakesMessages de R des fonctions statistiques, et les erreurs statistiques classiques

Method. Read the first message. Check the types of your columns (str()): most errors of statistical functions come from a number stored as text, a group with the wrong number of levels, or NA. Then restart R and re-run the script from the top.

Méthode. Lisez le premier message. Vérifiez les types de vos colonnes (str()) : la plupart des erreurs des fonctions statistiques viennent d’un nombre stocké comme texte, d’un groupe avec un mauvais nombre de niveaux, ou de NA. Puis redémarrez R et relancez le script depuis le début.
