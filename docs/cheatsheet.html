Reporting templatesModèles de rédaction

  • Mean with CI: “Mean weight was 631 g (95 % CI 581–680 g, n = 160).”
  • Two groups: “X was higher in A than in B (mean 54.7 vs 45.8 %; difference 8.9, 95 % CI 1.2–16.7; Welch t-test, t = 2.30, df = 78.0, p = 0.024).”
  • ANOVA: “Y differed among groups (one-way ANOVA, F₃,₂₀ = 8.19, p < 0.001, η² = 0.55); only C differed from D (Tukey HSD, …).”
  • χ²: “The share of A was higher among B (68 % vs 45 %; χ² = 19.4, df = 1, p < 0.001; odds ratio 4.3, 95 % CI …).”
  • Regression: “Height decreased by 0.17 m per PSU of salinity (95 % CI −0.24 to −0.11; R² = 0.47, n = 40).”
  • Moyenne avec IC : « Le poids moyen était de 631 g (IC 95 % 581–680 g, n = 160). »
  • Deux groupes : « X était plus élevé en A qu’en B (moyenne 54,7 contre 45,8 % ; différence 8,9, IC 95 % 1,2–16,7 ; test t de Welch, t = 2,30, ddl = 78,0, p = 0,024). »
  • ANOVA : « Y différait entre groupes (ANOVA à un facteur, F₃,₂₀ = 8,19, p < 0,001, η² = 0,55) ; seul C différait de D (HSD de Tukey, …). »
  • χ² : « La part de A était plus élevée chez B (68 % contre 45 % ; χ² = 19,4, ddl = 1, p < 0,001 ; odds ratio 4,3, IC 95 % …). »
  • Régression : « La hauteur diminuait de 0,17 m par PSU de salinité (IC 95 % −0,24 à −0,11 ; R² = 0,47, n = 40). »
