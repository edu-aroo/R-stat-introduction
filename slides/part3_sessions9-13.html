Deux variables catégorielles

tab <- table(fs$lmma_member, fs$supports_closure)
round(100 * prop.table(tab, 1))
#>      
#>       no yes
#>   no  46  54
#>   yes 16  84
ct <- chisq.test(tab); ct$p.value
#> [1] 1.064744e-05
fisher.test(tab[c("yes", "no"), c("yes", "no")])$estimate     # odds ratio

#>   4.261454

Séance 11 — Puissance, tests multiples, rédaction

Combien d’unités ?

power.t.test(delta = 150, sd = sd(oc$weight_g[oc$area == "open"]), power = 0.8)$n
#> [1] 70.48363
power.prop.test(p1 = 0.15, p2 = 0.05, power = 0.8)$n
#> [1] 140.0951
  • Plus d’effet, moins de variabilité, plus de n → plus de puissance
  • Pas de « puissance a posteriori » : donnez l’IC de l’effet

Tests multiples et p-hacking

p.adjust(c(0.004, 0.012, 0.030, 0.041, 0.20, 0.62), "holm")
#> [1] 0.024 0.060 0.120 0.123 0.400 0.620

Écrivez le plan d’analyse avant de voir les données.
