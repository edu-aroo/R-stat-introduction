Séance 5 — Erreur standard et IC

La distribution d’échantillonnage

  • Centrée sur μ · dispersion = σ / √n · forme → normale (théorème central limite)

ET, ES, IC

  • ET : variabilité des données · ES = s / √n : précision de la moyenne
  • IC à 95 % = estimation ± t × ES
w <- oc$weight_g[oc$area == "open"]
t.test(w)$conf.int
#> [1] 581.4663 680.0337
#> attr(,"conf.level")
#> [1] 0.95
binom.test(sum(w < 350), length(w))$conf.int
#> [1] 0.1037418 0.2219562
#> attr(,"conf.level")
#> [1] 0.95

« 95 % » qualifie la méthode : 95 % des intervalles contiennent μ.

Séance 6 — Tests et p-values

La logique d’un test (permutation)

re <- oc[oc$area == "reopened", ]
obs <- diff(rev(tapply(re$weight_g, re$fisher_sex, mean)))
set.seed(6)
perm <- replicate(5000, { s <- sample(re$fisher_sex)
  mean(re$weight_g[s == "F"]) - mean(re$weight_g[s == "M"]) })
mean(abs(perm) >= abs(obs))     # p-value
#> [1] 0.9672

Ce qu’est (et n’est pas) une p-value

  • Est : P(données au moins aussi extrêmes si H0 était vraie)
  • N’est pas : la probabilité que H0 soit vraie, ni la taille de l’effet
  • p > 0,05 ≠ « pas d’effet » · p < 0,001 ≠ « grand effet »

Séance 7 — Comparer deux groupes

Indépendants : Welch, log, Wilcoxon

oc$area <- factor(oc$area, levels = c("reopened", "open"))
tb <- t.test(log(weight_g) ~ area, data = oc)
exp(diff(rev(tb$estimate)))             # rapport des moyennes géométriques
#> mean in group reopened 
#>               1.536136
exp(tb$conf.int)
#> [1] 1.378137 1.712248
#> attr(,"conf.level")
#> [1] 0.95
wilcox.test(weight_g ~ area, data = oc, exact = FALSE)$p.value
#> [1] 4.295762e-13

Appariés : les mêmes colonies
